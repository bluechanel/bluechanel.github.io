## 成为什么样的人

研究者们公认一个事实：社会经济地位高的人群往往比普通人更自私。

> 第一，一个人能不能获得权力，能不能得到升职，他的工作业绩是一个不重要的因素。  
> 第二，决定你升职的最重要因素，是你跟上级的关系。

{% mark color="red" %}真正的积极主动，是你的行为完全取决于自身，而不被外界刺激所左右。{% /mark %}

## 人和环境

人和环境并不是不能改变的，如果我们把你自身的素质叫作“自身因素”，把你所处的环境叫作“外部因素”，那么这个道理是外部因素没有你自身因素重要，而最重要的则是你{% mark color="red" %}在这个环境里能构建出来什么东西{% /mark %}，是“构建”因素。

  
你不仅仅是适应环境，你的行为可以改变环境。一件事的好坏绝不是由一开始的设定决定的，而更多地是由你每一天的努力决定的，是你把自身因素和外部因素结合起来，和人一起构建出来的。


> 💡 维护关系的能力才是最重要的

# 教育

所以也许不是教育水平决定经济增长。也许是经济增长了以后，社会上有了更多高薪职位，人们为了能得到这些职位才对教育产生更大需求

人才和工作机会其实是共同增长的，而历史数据似乎显示，{% mark color="red" %}工作机会必须先走一步来带动教育发展{% /mark %}。

对聪明学生来说，上不上名校并不重要；低收入家庭的孩子上不上名校对他影响巨大

{% mark color="red" %}基尼系数为标准，收入分配越平均的国家，其家长对孩子的要求越强调“想象力”，教育手法越宽松；贫富差距越大的国家，家长越强调“努力拼搏”，教育风格也更独裁。{% /mark %}

{% mark color="orange" %}一般中产阶层的学校强调把事做“对”{% /mark %}

## 早教的危害

早教带来的早期优势会在1～3年内被冲刷掉，然后还可能会被逆转。

早教组的孩子不但成绩被人逆转，而且在{% mark color="red" %}社交和情感能力方面，还有明显的欠缺{% /mark %}。这才是早教最大的害处。

## 儿童教育方案

9个月以下的孩子不需要额外的音频和视频多媒体信息。长时间让孩子听音乐看电视会导致孩子长大以后不能集中注意力。

18个月以下的孩子只有听真人说话、在有互动的情况下，才能提高词汇量。其他方法一律没用而且有害。

2岁以下的儿童只适合接触三维的物体——也就是真实世界里那些寻常的物体，比如玩具和人。而二维的东西，比如书本和图画，只会妨碍他们感知能力的发育。

## 补习班的作用

2013年，哥伦比亚大学的一篇博士学位论文对韩国的补习班做了大量的研究，基本结论大约可以总结为三点：

1.课外补习对差生最有效果；

2.对数学和英语比较有效，对语文作用不大；

3.补习的效果主要发生在初中阶段。上了高中以后，课外补习只在数学方面而且只对差生有一定的效果。

所以更科学的结论是，{% mark color="red" %}考试成绩只是反映了学生家长和学生本人是什么人{% /mark %}，而不是他们**花了多少钱**。

父母只要避免暴力、虐待，不要漠不关心即可，除此之外，父母做的任何事情都不会产生显著影响。

所以{% mark color="red" %}智商是决定性的因素{% /mark %}。根据对大规模人群的统计，优秀不优秀主要是由智商决定的

## 自我成长

第一，你得有内在驱动力。这回不是为了父母、为了金钱或者职位这些外部的东西而战了，你得有个远大的目标，找到一个领域，发现一个使命，能自己驱动自己才行。

第二，你得能理解和处理复杂的问题。这回你不能甘当螺丝钉了，你得跳出流程，摆脱膝跳反应式的思维，掌控自己的思考，自己有见解、敢拿主意才行。

{% mark color="red" %}自控力是比想象力更为基本和行之有效的个人素质{% /mark %}，是摆脱贫困的关键一步

## 圣贤

谦卑，意思是必须承认{% mark color="red" %}自己和所有人一样都是有缺陷的{% /mark %}，思想中有很多偏见，性格中有很多弱点。

他们不问我想干什么，他们问世界需要我干什么。他们不是用做事的方法来满足内心。他们是为了做成这件事，去不断打磨自己的内心。

中庸，是你要{% mark color="red" %}认识到不同理念、不同情感诉求、不同道德标准之间，必然有冲突{% /mark %}。这些理念没有哪个是完美的，谁也说服不了谁，谁也消灭不了谁，矛盾永远存在。

所以领导的艺术就如同在风暴中驾驶帆船：太往左偏了就往右调整一下，太往右偏了就往左调整一下。{% mark color="red" %}平衡永远是动态的{% /mark %}。你就永远这么调啊调，这就是中庸之道。

## 教育的目的

主人学习审美，关心怎么评价别人；奴隶学习比美，关心别人怎么评价自己；主人学习明辨是非，奴隶学习迎合别人的是非观；主人学习怎么找到和使用工具，奴隶学习怎么把自己变成工具；主人学习合理调动资源，奴隶学习把自己变成别人的资源；{% mark color="red" %}主人学习“我想要什么”，奴隶学习“我要变成什么”。{% /mark %}

{% mark color="red" %}1.贫民家庭对教育的期待是培养工具，以找工作为目的。{% /mark %}

{% mark color="red" %}2.中产家庭对教育的期待是培养工艺品，以提升个人价值为目的。{% /mark %}

{% mark color="red" %}3.上层家庭对教育的期待是培养主人翁，以欣赏、选择和改变周围世界为目的。{% /mark %}

{% mark color="orange" %}1.低水平企业家/贫民教育：用户喜欢什么我就做什么。{% /mark %}

{% mark color="orange" %}2.中间水平企业家/中产教育：我做最好的自己，等着用户选我。{% /mark %}

{% mark color="orange" %}3.英雄企业家/上层教育：我替用户决定。{% /mark %}

所谓英雄，就是{% mark color="red" %}超越了阶层出身、超越了周围环境、超越了性格局限{% /mark %}，拒绝按照任何设定好的程序行事，不能被大数据预测，能给世界带来惊喜，最不像机器人的人。

所以{% mark color="red" %}真正了不起的事业应该由使命感驱动{% /mark %}，比如一个真正的政治家不应该是为了从政而有政治观点，而应该是有了政治观点才决定从政。

为什么英雄是自由的？因为一个人一旦有了使命感，就有了最彻底的主人翁精神，你就不用管他，也管不住他了。

你要测量一段话里有多少{% mark color="red" %}真正的信息，其实是看这段话给你带来多少意外(信息熵){% /mark %}。如果一切都是套话、废话，这段话就没有信息

你贡献了新的信息，世界因你而不同，历史才真的进步了。

## 权力的来源(权力只对权力的来源负责)

●名义选民：在名义上有选举权和被选举权的全体公民。然而他们中的很多人，可能对谁当领导人根本没有任何影响力。

●实际选民：那些真正对谁当领导人有影响力的人。对美国来说这相当于选举这天出来投票的选民，对沙特阿拉伯王国这样的君主国来说他们是皇室成员。

●胜利联盟：领导人维持自己权力必须依赖的人。对美国总统来说他们是在关键选区投出关键一票让你当选的人，对独裁者来说他们是你在军队和贵族内部的核心支持者。

要知道即使最厉害的独裁者也不可能按自己的意志为所欲为，他们必须依靠联盟才能实施统治。为此，领导人取悦的对象不是全体人民，而是联盟。

{% mark color="red" %}独裁体制收买少数人，西方民主体制收买多数人{% /mark %}，本质都是收买

### 保持权力(维护联盟)

1.要让联盟越小越好。联盟人数越少，收买他们要花的钱就越少。

2.要让名义选民越多越好。名义选民多，一旦联盟中有人对你不满，你就可以轻易替换掉他。

3.控制收入。领导人必须知道钱在哪儿，而且必须能控制钱的流动。

4.{% mark color="red" %}好好回报联盟对你的支持{% /mark %}。一定要给够，但是也不要过多。

5.绝对不要从联盟口袋里往外拿钱给人民。

因为对领导人来说，纵容警察腐败是比直接给他们发钱更方便的回报办法。

对领导人来说，联盟成员的能力并不重要，甚至反而有害，{% mark color="red" %}忠诚{% /mark %}才是最重要的。

他们都必须优先保证自己铁杆支持者的利益。

### 改革开放促进民主

{% mark color="red" %}民主的一个先决条件是政府必须是人民纳税养活的{% /mark %}。如果这个国家拥有丰富的石油之类的自然资源，独裁者只须把这个资源控制在自己手里就能确保有足够的收入去喂饱联盟，那么他在任何时候都不需要什么民主。

所谓民主和法治这些东西，并不是哪个强人自上而下赐予人民的，而是人民在市场交换过程中互相磨合和演化出来的。随着经济的发展，国家中会涌现出越来越多的敢于要求更多权利的人来。这些人如果足够多，他们将是所有政党都必须争取的对象。

# 未来

## 物质时代的稀缺品：排位稀缺

排位稀缺可以分为三种

**优越感**，代表能让你彰显比别人更高的“地位”的东西。

**进入权**，则是能在熙熙攘攘的人群之中给你某种特权的东西。

**引导力**，是给别人推荐什么东西，别人心悦诚服地接受的能力。

**优越感+进入权=圈子（Proximity）**

**引导力+优越感=正统（Legitimacy）**

**引导力+进入权=勒索（Extortion）**

> 与其感叹社会变化不如迎接社会变化。看看富人们还有什么好东西，能不能把它量产，这是一个长久不变的商业思路。

## 消费主义也许并非贬义

把钱送给穷人消费有利于社会进步。更重要的是，这么做还有利于经济增长。

第一，{% mark color="red" %}产生经济衰退的原因是剩余利润{% /mark %}。

第二，{% mark color="red" %}为扩大消费，应该做好财富的再分配{% /mark %}，比如增加社会福利。  
第三，投资应该社会化。决定一个项目是否上马，不应该只看其能带来多少利润，而应该全社会一起评估它的社会价值，也就是说要追求使用价值。

第四，花钱是道德的，消费文化是个好东西。
